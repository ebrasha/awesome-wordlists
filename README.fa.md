# مرجع جامع واژه‌نامه‌ها، ابزارهای دیکشنری‌اتک و پی‌لودهای فازینگ برای تست نفوذ و عملیات تیم قرمز

جامع‌ترین مخزن موجود در GitHub که به‌عنوان یک مجموعهٔ مرجع متمرکز و کاملاً بهینه‌سازی‌شده از واژه‌نامه‌ها (Wordlists)، داده‌های حملات دیکشنری و پی‌لودهای پیشرفتهٔ فازینگ، به‌طور ویژه برای متخصصان امنیت، تسترهای نفوذ و هکرهای اخلاق‌مدار طراحی و گردآوری شده است.

---

## 🎯 چرا این مخزن ایجاد شده است؟

در طول ارزیابی‌های امنیتی و تست‌های نفوذ، دسترسی فوری به داده‌های ساختاریافته و باکیفیت از اهمیت حیاتی برخوردار است. واژه‌نامه‌های استاندارد اغلب پراکنده، قدیمی یا مملو از داده‌های تکراری هستند که سرعت حملات Brute-Force و فازینگ وب را به‌شدت کاهش می‌دهند.

این مخزن برای پر کردن این شکاف ایجاد شده است. این پروژه به‌عنوان یک مؤلفهٔ زیرساختی ضروری برای ایستگاه کاری هر تستر امنیتی عمل می‌کند. با تجمیع فهرست‌های چندمنظوره در یک مخزن واحد و ساختاریافته، می‌توانید آن را در هر محیط تست به‌سرعت کلون کرده و بلافاصله حملات دیکشنری هدفمند، کشف دایرکتوری یا تزریق پی‌لود را اجرا کنید.

## 📂 محتوا و ساختار مخزن

مجموعه‌داده‌های این مخزن به‌صورت راهبردی دسته‌بندی و بهینه شده‌اند تا حداکثر سرعت، حداقل نویز و بالاترین نرخ موفقیت را در عملیات تست نفوذ فعال و هک اخلاق‌مدار فراهم آورند. در ادامه، تشریح کاملی از نقشهٔ ساختاری این مخزن ارائه می‌شود:

### 🤖 ۱. هوش مصنوعی (AI) و امنیت مدل‌های زبانی بزرگ (`/Ai`)
مجموعه‌ای پیشرو که برای تست‌های خصمانه (Adversarial)، راستی‌آزمایی هم‌راستایی ایمنی و عملیات Red-Team بر روی مدل‌های مدرن LLM و هوش مصنوعی طراحی شده است:
* **تست تعصب و انصاف (Bias & Fairness):** واژه‌نامه‌های استاندارد (`gender_bias.txt`، `race_ethnicity_bias.txt`) برای ممیزی هم‌راستایی مدل‌ها.
* **نشت داده و حریم خصوصی:** پی‌لودهای هدفمند برای شبیه‌سازی بازیابی تصادفی PII و افشای فراداده‌ها (`personal_data.txt`).
* **پرامپت‌های خصمانه و Jailbreak:** مجموعه‌ای از پرامپت‌های تزریقی تاریخی و تکامل‌یافته که برای دور زدن مرزهای مدل و آزمایش محدودیت‌های سختگیرانهٔ هم‌راستایی طراحی شده‌اند.

### 🔍 ۲. فازینگ وب، کشف دارایی‌ها و شناسایی (`/Discovery`)
فهرست‌های جامع و ساختاریافته برای ترسیم تهاجمی سطح حملهٔ سازمانی در لایه‌های شبکه، اپلیکیشن و زیرساخت:
* **شمارش دایرکتوری و فایل:** شامل واژه‌نامه‌های با دقت بالا مانند سری‌های گردآوری‌شدهٔ `raft` و `DirBuster` برای شناسایی مسیرهای پنهان وب، درهای پشتی سیستم و محل قرارگیری Shell‌ها.
* **زیرساخت و شبکه:** فهرست‌های شمارش زیردامنه (شامل واریانت‌های ترکیبی Top 1M)، پسوندهای رایج وب، نام سرویس‌ها و رشته‌های Community سفارشی SNMP (`snmp.txt`).
* **CMSها و زمینه‌های محیطی:** نقاط پایانی (Endpoint) بسیار تخصصی برای سیستم‌های سازمانی و سامانه‌های مدیریت محتوا، شامل مسیرهای جامع برای پلاگین‌ها/پوسته‌های WordPress، Drupal، Joomla، Apache، Nginx، Tomcat و WebSphere.

### 🔑 ۳. احراز هویت و اعتبارنامه‌ها (رمزهای عبور و مجموعه‌داده‌های نشت‌یافته)
فهرست‌های اصلی متمرکز بر Credential Stuffing با سرعت بالا، ممیزی دسترسی‌های پیش‌فرض و حملات پیچیدهٔ دیکشنری مبتنی بر Brute-Force:
* **اعتبارنامه‌های نشت‌یافته و دامپ‌ها:** واریانت‌های بهینه‌شده از مجموعه‌داده‌های افسانه‌ای نشت‌یافته (مانند بخش‌های مرتب‌شدهٔ `rockyou`، `myspace` و الگوهای تاریخی نشت‌یافتهٔ جوامع) با یا بدون شمارش تکرار.
* **سوابق دسترسی پیش‌فرض:** نگاشت‌های گسترده‌ای از حساب‌های پیش‌فرض تولیدکنندگان، رمزهای استاندارد روترها، شناسه‌های تراکنش CICS و پروفایل‌های اعتبارنامهٔ چندبرندی CCTV/DVR.
* **محیط‌های هدفمند:** فایل‌های اعتبارنامهٔ سفارشی، ساختاریافته برای پروتکل‌های شبکهٔ خاص (SSH، Telnet، حساب‌های root پایگاه‌داده و پروفایل‌های IPMI).

### ⚡ ۴. پی‌لودهای تزریق، فازینگ و جهش (Mutation)
پی‌لودهای پیشرفته که برای اعتبارسنجی نقاط ضعف لایهٔ اپلیکیشن و فیلتر کردن موارد لبه‌ای غیرقابل اکسپلویت گردآوری شده‌اند:
* **نقاط ضعف سمت سرور:** فهرست‌های پویا با هدف Local File Inclusion (LFI) بهینه‌شده برای مسیرهای Unix/Windows، Remote File Inclusion و بازنویسی متغیرهای سیستمی.
* **مؤلفه‌های بومی وب:** نگاشت‌های جامع برای پارامتر‌یابی (`burp-parameter-names.txt`)، کشف API (`api-endpoints.txt`) و فهرست‌های فاز PHP سفارشی که برای شکستن فیلترهای اعتبارسنجی ورودی طراحی شده‌اند.

*   **مسئولیت کاربر:** مسئولیت نهایی استفاده از این واژه‌نامه‌ها به‌طور کامل بر عهدهٔ کاربر نهایی است. نگه‌دارنده هیچ‌گونه مسئولیتی در قبال سوءاستفاده، حملات غیرمجاز، نشت داده‌ها یا پیامدهای قانونی ناشی از استفاده از این فایل‌ها نمی‌پذیرد.
*   **انطباق با قوانین:** پیش از آغاز هرگونه ارزیابی امنیتی، حملهٔ دیکشنری یا فازینگ، اطمینان حاصل کنید که مجوز صریح و کتبی از سازمان هدف یا مالک دارایی دریافت کرده‌اید.
