GitHub 上で最も網羅的なリポジトリであり、セキュリティ専門家、ペネトレーションテスター、そしてエシカルハッカーのために特別に整備された、ワードリスト・辞書攻撃データ・高度なファジングペイロードを集約・最適化したマスターコレクションとして機能します。

---

## 🎯 このリポジトリが存在する理由

セキュリティ評価やペネトレーションテストにおいて、構造化された高品質なデータへ即座にアクセスできることは極めて重要です。一般的なワードリストはしばしば散在し、古くなっていたり、冗長なデータで埋め尽くされており、ブルートフォース攻撃や Web ファジングの速度を低下させてしまいます。

本リポジトリは、その隔たりを埋めるために作成されました。これはセキュリティテスターのワークステーションにとって不可欠なインフラ要素です。多目的リストを一つの構造化されたリポジトリに統合することで、あらゆるテスト環境に素早くクローンし、標的型の辞書攻撃、ディレクトリ探索、ペイロードインジェクションを即座に展開できます。

---

## 📂 リポジトリの内容と構成

本リポジトリのデータセットは、能動的なペネトレーションテストおよびエシカルハッキングの場面において、速度を最大化し、ノイズを最小限に抑え、高い成功率を確保できるよう、戦略的に分類・最適化されています。以下に本リポジトリの構造を網羅的に解説します:

### 🤖 1. 人工知能 (AI) と LLM セキュリティ (`/Ai`)
最新の LLM および AI モデルに対する敵対的テスト、安全性アラインメントの検証、レッドチーム演習のために設計された最先端コレクション:
* **バイアスおよび公平性テスト:** モデルのアラインメントを監査するための標準化された辞書 (`gender_bias.txt`、`race_ethnicity_bias.txt`)。
* **データ漏洩とプライバシー:** 偶発的な PII 取得およびメタデータ露呈を模擬するための標的型ペイロード (`personal_data.txt`)。
* **敵対的プロンプトおよび Jailbreak プロンプト:** モデルの境界を回避し、厳格なアラインメント制約を試験するための、歴史的かつ進化型のプロンプトインジェクションセット。

### 🔍 2. Web ファジング、資産発見、偵察 (`/Discovery`)
ネットワーク層、アプリケーション層、インフラ層を横断して、エンタープライズ規模の攻撃対象領域を積極的にマッピングするために構成された包括的なリスト:
* **ディレクトリ・ファイル列挙:** 隠された Web パス、システムバックドア、シェルの設置場所を特定するために厳選された `raft` および `DirBuster` シリーズなど、高精度のワードリストを含みます。
* **インフラとネットワーク:** サブドメイン列挙リスト(Top 1M 統合バリアントを含む)、一般的な Web 拡張子、サービス名、カスタマイズされた SNMP コミュニティ文字列 (`snmp.txt`)。
* **CMS および環境コンテキスト:** WordPress プラグイン/テーマ、Drupal、Joomla、Apache、Nginx、Tomcat、WebSphere の包括的パスを含む、エンタープライズシステムおよびコンテンツ管理システム向けの高度に特化したエンドポイント。

### 🔑 3. 認証と資格情報(パスワードおよび漏洩データセット)
高速なクレデンシャルスタッフィング、デフォルトアクセス監査、高度なブルートフォース辞書攻撃に特化したマスターリスト:
* **漏洩した資格情報とダンプ:** 出現回数の有無を選択できる、伝説的な漏洩データセット(ソート済み `rockyou` シャード、`myspace`、過去に漏洩したコミュニティパターンなど)の最適化済みバリアント。
* **デフォルトアクセスログ:** ベンダーのデフォルトアカウント、標準ルーターパスワード、CICS トランザクション ID、マルチベンダー CCTV/DVR 資格情報プロファイルの広範なマッピング。
* **特定環境向け:** 特定のネットワークプロトコル(SSH、Telnet、データベース root、IPMI プロファイル)向けに構造化された、用途特化型の資格情報ファイル。

### ⚡ 4. インジェクション・ファジング・ミューテーション用ペイロード
アプリケーション層の脆弱性を検証し、悪用不能なエッジケースを除外するために編集された高度なペイロード:
* **サーバーサイドの脆弱性:** Unix/Windows パスに最適化されたローカルファイルインクルージョン (LFI)、リモートファイルインクルージョン、システム変数の上書きを標的とする動的リスト。
* **Web ネイティブコンポーネント:** パラメータ探索 (`burp-parameter-names.txt`)、API ディスカバリー (`api-endpoints.txt`)、入力検証フィルタを突破するために設計されたカスタム PHP ファズリストの包括的マッピング。
