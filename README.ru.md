Самый исчерпывающий репозиторий на GitHub, представляющий собой централизованную и высокооптимизированную мастер-коллекцию словарей, данных для словарных атак и продвинутых полезных нагрузок для фаззинга, специально адаптированных для специалистов по безопасности, пентестеров и этичных хакеров.

---

## 🎯 Зачем существует этот репозиторий

В ходе оценки безопасности и тестирования на проникновение критически важно иметь немедленный доступ к хорошо структурированным и качественным данным. Стандартные словари часто разрозненны, устарели или содержат избыточные данные, что замедляет атаки методом перебора и веб-фаззинг.

Этот репозиторий был создан, чтобы устранить этот пробел. Он служит важнейшим инфраструктурным компонентом рабочей станции специалиста по безопасности. Объединяя многоцелевые списки в единый структурированный репозиторий, вы можете быстро клонировать его в любую тестовую среду и немедленно развернуть целенаправленные словарные атаки, обнаружение каталогов или внедрение полезных нагрузок.

---

## 📂 Содержимое и структура репозитория

Наборы данных в этом репозитории стратегически классифицированы и оптимизированы для максимального увеличения скорости, минимизации шума и обеспечения высокой эффективности при активном тестировании на проникновение и этичном хакинге. Ниже представлена подробная разбивка структурного плана репозитория:

### 🤖 1. Безопасность искусственного интеллекта (ИИ) и LLM (`/Ai`)
Передовая коллекция, разработанная для состязательного тестирования, проверки безопасности модели и проведения red-team операций против современных LLM и ИИ-моделей:
* **Тестирование предвзятости и справедливости:** Стандартизированные словари (`gender_bias.txt`, `race_ethnicity_bias.txt`) для аудита соответствия моделей.
* **Утечка данных и конфиденциальность:** Целевые полезные нагрузки для симуляции случайного извлечения PII и раскрытия метаданных (`personal_data.txt`).
* **Состязательные и jailbreak-промпты:** Исторические и эволюционировавшие наборы инъекций промптов, предназначенные для обхода границ модели и проверки строгих ограничений выравнивания.

### 🔍 2. Веб-фаззинг, обнаружение активов и разведка (`/Discovery`)
Комплексные списки, структурированные для агрессивного картирования поверхности атаки предприятия на уровнях сети, приложений и инфраструктуры:
* **Перечисление каталогов и файлов:** Включает высокоточные словари, такие как тщательно отобранные серии `raft` и `DirBuster` для выявления скрытых веб-путей, системных бэкдоров и расположения веб-шеллов.
* **Инфраструктура и сеть:** Списки для перечисления поддоменов (включая комбинированные варианты Top 1M), распространенные веб-расширения, имена сервисов и пользовательские строки сообщества SNMP (`snmp.txt`).
* **CMS и контекст окружения:** Высокоспециализированные эндпоинты для корпоративных систем и систем управления контентом, включая полные пути для плагинов/тем WordPress, Drupal, Joomla, Apache, Nginx, Tomcat и WebSphere.

### 🔑 3. Аутентификация и учётные данные (пароли и наборы данных утечек)
Мастер-списки, ориентированные на высокоскоростной credential stuffing, аудит доступа по умолчанию и сложные словарные атаки методом перебора:
* **Утекшие учётные данные и дампы:** Оптимизированные варианты легендарных наборов данных утечек (таких как отсортированные шарды `rockyou`, `myspace` и исторические утекшие шаблоны сообществ) с подсчётом вхождений или без него.
* **Журналы доступа по умолчанию:** Обширные карты учётных записей вендоров по умолчанию, стандартных паролей маршрутизаторов, идентификаторов транзакций CICS и многовендорных профилей учётных данных CCTV/DVR.
* **Целевые окружения:** Специально подобранные файлы учётных данных, структурированные для конкретных сетевых протоколов (SSH, Telnet, root-учётные записи баз данных и профили IPMI).

### ⚡ 4. Полезные нагрузки для инъекций, фаззинга и мутаций
Продвинутые полезные нагрузки, собранные для проверки уязвимостей прикладного уровня и отсеивания неэксплуатируемых пограничных случаев:
* **Уязвимости на стороне сервера:** Динамические списки, нацеленные на Local File Inclusion (LFI), оптимизированные для путей Unix/Windows, Remote File Inclusion и переопределение системных переменных.
* **Нативные веб-компоненты:** Комплексные карты для поиска параметров (`burp-parameter-names.txt`), обнаружения API (`api-endpoints.txt`) и пользовательские PHP-списки для фаззинга, предназначенные для обхода фильтров валидации ввода.
