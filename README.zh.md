## 🎯 本仓库存在的意义

在安全评估和渗透测试过程中,能够即时访问结构良好且高质量的数据至关重要。标准字典往往分散、过时,或充斥着冗余数据,从而拖慢暴力破解攻击和 Web 模糊测试的进度。

本仓库的创建正是为了弥合这一差距。它是安全测试人员工作站不可或缺的基础设施组件。通过将多用途列表整合到一个结构化的仓库中,您可以快速将其克隆到任何测试环境中,并立即部署定向字典攻击、目录发现或载荷注入。

---

## 📂 仓库内容与结构

本仓库中的数据集经过战略性分类与优化,旨在最大限度地提升速度、降低噪声,并在主动渗透测试和道德黑客实战中确保高成功率。以下是本仓库结构蓝图的全面剖析:

### 🤖 1. 人工智能 (AI) 与大语言模型安全 (`/Ai`)
为现代 LLM 与 AI 模型的对抗性测试、安全对齐验证及红队演练而精心打造的前沿集合:
* **偏见与公平性测试:** 标准化字典(`gender_bias.txt`、`race_ethnicity_bias.txt`)用于审计模型对齐情况。
* **数据泄露与隐私:** 用于模拟个人身份信息 (PII) 意外检索和元数据暴露的定向载荷(`personal_data.txt`)。
* **对抗性与越狱提示:** 历史与演化的提示注入集合,旨在突破模型边界并测试严格的对齐约束。

### 🔍 2. Web 模糊测试、资产发现与侦察 (`/Discovery`)
结构化的综合列表,用于在网络、应用程序及基础设施层面全面映射企业攻击面:
* **目录与文件枚举:** 包含高保真字典,如精心整理的 `raft` 与 `DirBuster` 系列,用于发现隐藏的 Web 路径、系统后门及 Shell 位置。
* **基础设施与网络:** 子域名枚举列表(包括 Top 1M 合并变体)、常见 Web 扩展名、服务名称以及自定义 SNMP 社区字符串(`snmp.txt`)。
* **CMS 与环境上下文:** 针对企业系统与内容管理系统的高度专用端点,包括 WordPress 插件/主题、Drupal、Joomla、Apache、Nginx、Tomcat 及 WebSphere 的完整路径。

### 🔑 3. 认证与凭据(密码与泄露数据集)
专注于高速凭据填充、默认访问审计以及复杂暴力破解字典攻击的主列表:
* **泄露凭据与数据转储:** 经过优化的传奇泄露数据集变体(如已排序的 `rockyou` 分片、`myspace`,以及历史泄露的社区模式),包含或不包含出现次数计数。
* **默认访问日志:** 涵盖默认厂商账户、标准路由器密码、CICS 事务 ID 以及多厂商 CCTV/DVR 凭据档案的广泛映射。
* **目标环境:** 针对特定网络协议(SSH、Telnet、数据库 root 账户及 IPMI 档案)定制的凭据文件。

### ⚡ 4. 注入、模糊测试与变异载荷
为验证应用层漏洞并过滤掉不可利用的边缘情况而编译的高级载荷:
* **服务器端漏洞:** 针对本地文件包含 (LFI) 的动态列表,针对 Unix/Windows 路径、远程文件包含及系统变量覆盖进行了优化。
* **Web 原生组件:** 用于参数挖掘(`burp-parameter-names.txt`)、API 发现(`api-endpoints.txt`)以及旨在突破输入验证过滤器的自定义 PHP 模糊测试列表的全面映射。
