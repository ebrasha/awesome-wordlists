# 🔐 وردلیست تست نفوذ RDP — محتمل‌ترین نام‌های کاربری و رمزهای عبور برای Brute Force و Password Spraying روی Remote Desktop ویندوز

### 👤 ابراهیم شفیعی (EbraSha) 🇮🇷

یک پک وردلیست دقیق، واقع‌گرا و با سیگنال بالا، طراحی‌شده به‌طور اختصاصی برای تست نفوذ **مجاز** سرویس **Microsoft Windows RDP (Remote Desktop Protocol)** روی پورت `3389`. این وردلیست بر اساس دیتاست‌های لو رفته (breach corpora)، پسوردهای پیش‌فرض ونـدورها، سیاست‌های رمز عبور سازمانی، الگوهای فصلی و عادت‌های ادمین‌ها در محیط‌های Production ساخته شده است.

---

## 📌 چرا این پروژه ساخته شد؟

اکثر وردلیست‌های عمومی مثل `rockyou.txt` یا `SecLists` برای حمله به RDP **بسیار بزرگ، عمومی و پر سر و صدا** هستند. سرویس RDP ویژگی‌های منحصربه‌فردی دارد که استفاده از لیست‌های عمومی را ناکارآمد و خطرناک می‌کند:

- **سیاست پیش‌فرض قفل‌شدن اکانت (Account Lockout)** معمولاً بعد از ۳ تا ۵ تلاش ناموفق، حساب کاربری را قفل می‌کند.
- احراز هویت **NTLM / Kerberos** خیلی سریع لاگ‌های Event Viewer را پر می‌کند و آلارم‌های SIEM را فعال می‌کند.
- در محیط‌های **Domain-joined** نیاز به **Password Spraying** هدفمند و کم‌حجم است، نه Brute Force با سرعت بالا.
- ادمین‌های واقعی از یک مجموعهٔ کوچک، تکراری و قابل پیش‌بینی از الگوها (فصلی، وندوری، Policy-compliant) استفاده می‌کنند.

این پروژه با ارائهٔ **دو فایل کوچک، دقیق و با احتمال موفقیت بالا** به جای میلیون‌ها کاندیدای نویزی، این مشکلات را حل می‌کند — شانس موفقیت در هر درخواست را به حداکثر و احتمال شناسایی شدن و قفل شدن اکانت را به حداقل می‌رساند.

## ✨ ویژگی‌ها و قابلیت‌ها

- 🎯 **اختصاصی RDP**: تنظیم‌شده برای Windows Server، Active Directory و ایستگاه‌های کاری سازمانی.
- 🧠 **سیگنال بالا، حجم کم**: کیفیت به جای کمیت — مهندسی‌شده برای **Password Spraying** نه Brute Force کور.
- 🏢 **الگوهای واقعی سازمانی**: رمزهای فصلی (`Summer2025!`)، فصلی-سه‌ماهه (`Q1@2026`) و ماهانه (`June2026`) که توسط سیاست‌های تغییر رمز ۹۰ روزه اعمال می‌شوند.
- 🔧 **رمزهای پیش‌فرض وندورها و سرویس‌ها**: VMware، Veeam، Cisco، Fortinet، Citrix، Synology، iLO، iDRAC، IPMI، Oracle، MSSQL و بسیاری دیگر.
- 👥 **اکانت‌های سرویس و ادمین**: `svc_sql`, `svc_backup`, `svc_veeam`, `svc_exchange`, `krbtgt`, `DefaultAccount`, `WDAGUtilityAccount` و …
- ☁️ **هویت‌های ابری و هیبریدی**: Azure AD، Office 365، AWS (`ec2-user`)، Intune، SharePoint و Teams.
- 🔣 **الگوهای Leetspeak و جایگزینی کاراکتر**: `P@55w0rd`, `4dm1n@123`, `W1nd0ws!`, `S3rv3r@2026`.
- ⌨️ **رمزهای Keyboard-walk**: `1qaz2wsx`, `qweasdzxc`, `zaq1!QAZ`, `1qaz!QAZ`.
- 🌍 **اعتبارنامه‌های بومی‌سازی‌شده**: شامل رمزهای مرتبط با Iran/Tehran و الگوهای رایج اسامی فارسی.
- ⚖️ **سازگار با Policy**: تمام رمزها با سیاست‌های پیچیدگی AD سازگارند (طول ≥ ۸، حرف بزرگ، عدد، علامت).
- 📝 **سازگار با ابزارها**: کامنت‌ها با `#` شروع می‌شوند تا توسط Hydra، Medusa، CrackMapExec، NetExec و Ncrack به‌صورت خودکار نادیده گرفته شوند.

## 🚀 نحوهٔ استفاده

> ⚠️ **توقف**: این وردلیست‌ها را **فقط** علیه سیستم‌هایی استفاده کنید که **مالک آن‌ها هستید** یا **مجوز کتبی صریح** برای تست آن‌ها دارید. استفادهٔ غیرمجاز جرم محسوب می‌شود.

### 🔧 NetExec / CrackMapExec (توصیه‌شده)

</div>

```bash
netexec rdp <target> -u rdp_usernames.txt -p rdp_passwords.txt --continue-on-success
```

<div dir="rtl">

### 🐉 Hydra (آهسته، ایمن از نظر Lockout)

</div>

```bash
hydra -L rdp_usernames.txt -P rdp_passwords.txt rdp://<target> -t 1 -W 3
```

<div dir="rtl">

### 🛡️ Ncrack

</div>

```bash
ncrack -vv --user rdp_usernames.txt -P rdp_passwords.txt rdp://<target>
```

### 💧 استراتژی توصیه‌شده برای Password Spraying

برای جلوگیری از قفل شدن اکانت‌ها و فعال شدن آلارم‌های SIEM:

۱. ابتدا **یک رمز را روی تمام نام‌های کاربری** امتحان کنید، سپس به رمز بعدی بروید.  
۲. بین هر دور، **حداقل ۳۰ دقیقه تأخیر** بگذارید تا شمارندهٔ Lockout ریست شود.  
۳. حتماً قبل از شروع، **سیاست Lockout دامین** را بررسی کنید (`net accounts /domain`).  
۴. کار را با رمزهای **فصلی / سال جاری** شروع کنید (`Summer2026!`, `Winter@2026`) — این‌ها بیشترین نرخ موفقیت را دارند.
