# Ultimate Global Geography & 6-Digit Wordlist

A massive, high-utility security research wordlist engineered for penetration testing, credential stuffing simulations, and dictionary attacks. This dataset maps every official country, state, and city across the globe, combined dynamically with human-centric password mutations and high-probability 6-digit numeric patterns.



## 📊 Dataset Scale & Disk Footprint

* **Total Password Entries**: **392,000,000+** unique generated lines.
* **Format**: Plain Text (`.txt`) with standard LF (`\n`) line endings.
* **Compressed Size**: Extremely compact when zipped/tarred due to text repetition patterns.
* **Uncompressed Storage Size**: **Approximately 6 GB** of raw, pure text password combinations.
* **Target Scope**: 150,000+ verified global locations mutated into a massive 392-million-row dictionary.

## ⚡ Matrix Architecture & Efficiency

This wordlist does not just guess randomly; it targets the specific mental formulas humans use when forcing compliance with modern password complexity rules.

### 1. Human Keyboard & Casing Mutations
Every geographic location in the world (e.g., **"Tehran"**) is extracted, stripped of invalid spaces/hyphens (e.g., `"New York"` $\rightarrow$ `"NewYork"`), and expanded into 6 psychological typing patterns:
* **Standard**: `tehran` (Lower), `Tehran` (Capitalized), `TEHRAN` (Upper)
* **Caps Lock Error**: `tEHRAN` (Accidental Shift inversion)
* **Keyboard Lag**: `TEhran` (Holding Shift too long)
* **Alternating / Chaos Case**: `TeHrAn` / `tEhRaN` (Manual complexity bypass)

### 2. Smart 6-Digit Numeric Padding
Every single casing mutation is cross-combined in a two-way matrix (`[Word][Number]` and `[Number][Word]`) with highly practical 6-digit chains:
* **Common Sequences**: `123456`, `654321`, `102030`, etc.
* **Keyboard Repeats**: `111111`, `999999`, `000000`, etc.
* **Birth & Event Years**: Comprehensive Solar Hijri (e.g., `135000` to `140600`) and Gregorian years (e.g., `197000` to `202600`) padded intelligently to meet the 6-digit threshold.
